Introduction

Problem Statement

Small & medium supermarkets still rely on manual registers, leading to…

📝

Manual Errors

Handwritten bills cause calculation mistakes & GST miscalculations

📦

Stock Mismatch

No real-time tracking leads to overstocking or stockouts

📊

No Analytics

Inability to track daily sales, top products, or revenue trends

🔓

No Security

Anyone can access billing and product data without authentication

Objective

What We Built

A web-based Supermarket Management System that digitises billing, inventory, and analytics

🎯 Goals

  • Automate billing with GST & discount calculations
  • Real-time inventory tracking with auto stock reduction
  • Dashboard with sales charts & low-stock alerts
  • Secure login with role-based access (Admin / Cashier)
  • Printable invoice generation
  • CSV bulk product import

✅ Key Benefits

  • Eliminates manual calculation errors
  • Instant low-stock alerts (threshold: 10 units)
  • 30-day sales trends & top products analytics
  • Complete bill history with reprint capability
  • Multi-payment mode support (Cash / UPI / Card)
  • Responsive, modern dark-themed UI

Workflow

Billing Process Flow

1
Search Product — Cashier searches by name; product list loads via API
↓
2
Add to Cart — Select product, enter quantity; line total calculated instantly
↓
3
Auto GST Calculation — GST computed per item based on stored gst_percent
↓
4
Apply Discount — Optional flat discount subtracted from grand total
↓
5
Generate Bill — POST /api/bills → stock reduced → bill saved → invoice printed

💡 Key Logic — BillService.java

@Transactional public Bill createBill(BillRequest req) { // Validate cart is not empty for (item : req.items()) { Product p = productRepo.findById(id); // Check stock availability p.setStock(p.getStock() - qty); // Calculate line total & GST line = price x quantity; gst = line x gstPercent / 100; } grandTotal = subtotal + gstTotal - discount; return billRepo.save(bill); }

✓ Entire operation is @Transactional
✓ Stock & bill saved atomically — no partial updates

Security

Authentication & Authorization

🔒 Spring Security Setup

  • Form-based login with custom Thymeleaf login page
  • BCrypt password encoding (industry standard)
  • CSRF protection enabled for form endpoints
  • CSRF disabled for /api/** (JS fetch calls)
  • Remember Me cookie — 7-day validity
  • Session management with JSESSIONID cookie cleanup on logout
